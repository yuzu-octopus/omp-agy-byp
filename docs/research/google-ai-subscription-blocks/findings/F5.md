## Angle

F5 — cross-vendor comparison of how AI vendors separate **consumer-subscription entitlement** (ChatGPT Plus/Pro, Claude Pro/Max/Ultra, X/Grok consumer plans, consumer Copilot/M365, GitHub Copilot) from **API access** (platform API keys, Console, Azure, separate metered billing), and what documented mechanisms block or gate using subscription credentials outside official clients. Scope: primary vendor docs, ToS, help articles, changelogs, and first-party staff posts. Practitioner reproductions (HN email artifact, GitHub issues) are tagged as first-hand reports, not vendor documentation. No exploit code; no legal conclusion. Google is excluded (another worker covers it). All sources below fetched 2026-11-18 unless a post date is given.
