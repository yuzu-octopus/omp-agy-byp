## Conflicting evidence

- **"gemini-cli binds Google AI Pro/Ultra" vs "gemini-cli no longer serves consumer plans".** Code on `main` still implements the full Pro/Ultra-capable OAuth→Code Assist path and docs still describe Pro/Ultra tiers (claims 12, 20–21), but the same docs and the README/blog say consumer requests stopped being served by Gemini CLI on 2026-06-18 and moved to Antigravity CLI (claims 22, 24). Resolution: code path is retained for Code Assist Standard/Enterprise and as historical Pro/Ultra evidence; do not claim current Gemini CLI serves consumer subscriptions.
- **"`~/.gemini/oauth_creds.json` is the credential store" vs "keychain".** Both are true with a flag: default `cacheCredentials()` writes the 0600 JSON file; `GEMINI_FORCE_ENCRYPTED_FILE_STORAGE=true` routes to `HybridTokenStorage`, which itself may use OS keychain or encrypted-file fallback (claims 5–6). Older write-ups citing only the JSON file are incomplete as of fetched `main`.
- **Preview-model access: client config vs server quota.** `resolveModel()` can downgrade based on `hasAccessToPreviewModel`, but that flag is populated from server `retrieveUserQuota` buckets (claim 19); API-key/Vertex modes set it true unconditionally (claim 19). So the allowlist is server-driven for OAuth, client-assumed for API key.
- **Client metadata `GEMINI_CLI` vs `IDE_UNSPECIFIED`.** `ClientMetadataIdeType` includes `GEMINI_CLI` and telemetry uses `getClientMetadata()`, but `setup.ts`/`server.ts` `loadCodeAssist()` and `refreshAvailableCredits()` explicitly send `ideType: 'IDE_UNSPECIFIED', platform: 'PLATFORM_UNSPECIFIED'` (claims 12, 15). Different calls carry different identity detail; no Google explanation found.
- **Practitioner 403 reports vs official docs saying individual accounts need no project.** Docs say most individual accounts need no GCP project (claim 21); issues #25189/#25431/#25603 report server-returned ghost projects causing 403 for paid personal accounts (claim 27). Unresolved in first-party docs.
- Antigravity docs say credentials are shared across local surfaces; Gemini CLI code shows per-platform credential paths with no cross-product sharing. Different products/epochs; no shared implementation publicly visible (claims 6, 22, 25).
