## Angle

Angle 4 — inbound reverse translation on the built-in `antigravity-acp` path. Can ACP/MCP tool calls and results be rewritten so omp continues to see canonical tool ids/calls, and which rewrites preserve vs. detach the stateful loop? All sources are installed omp 18.22.2 (`@oh-my-pi`) source; paths below are relative to that package root. Fetch date for every source: 2026-11-18. Confidence tags: `primary` = direct read of installed source; `inference` = reasoning over primary anchors; `speculative` = unverified.

## Claims

1. FACT: Two distinct inbound channels exist. (a) ACP `tool_call` sessionUpdate whose `title` matches `mcp_ide-tools_<name>` feeds ONLY announcement bookkeeping (`#announced`/`#announcementWaiters`). (b) The loopback NDJSON MCP `tools/call` request is the actual dispatch entry. Source: pi-ai/src/providers/antigravity-cli/host.ts:48,709-716; pi-ai/src/providers/antigravity-cli/mcp-bridge.ts:158-191. Date: 2026-11-18. Confidence: primary.

2. FACT: omp advertises tools to the MCP server with canonical names — `toMcpTool` sets `name: tool.name`; bridge `byName` and host `agy.tools` are both keyed by canonical `tool.name`. The `mcp_ide-tools_` prefix is agy CLI's projection, not minted by omp; regex extraction in `#onUpdate` is cosmetic (gates a waiter) and never reaches dispatch. Source: host.ts:855-859; mcp-bridge.ts:52; host.ts:425,710-714. Date: 2026-11-18. Confidence: primary.

3. FACT: `#onToolCall` gates before any tool call is emitted: process-token match, tool exists in map, `#awaitAnnouncement(name)`, active non-aborted step, conversation id present, `_meta["antigravity.google/conversation_id"] === conversation.id`, no existing `#pending`, live non-cancelling turn. Source: host.ts:626-652; mcp-bridge.ts:172-177. Date: 2026-11-18. Confidence: primary.

4. FACT: Invalid-arg handling is a safe no-op for the loop: `validateJsonSchemaValue(tool.inputSchema, args)` and `isRecord(args)`; on failure it returns `errorOutput(describeToolArguments(...))` with `isError:true` and emits NO `step.writer.toolCall`, so no step, no digest, no ledger change — agy sees an MCP error and can retry. Source: host.ts:653-655,872-874,883-920. Date: 2026-11-18. Confidence: primary.

5. FACT: The reverse-translation step mints `id = agy_${crypto.randomUUID().replaceAll("-","")}`, parks a `PendingCall` (state "parked", expiry timer = holdLimitMs), emits `step.writer.toolCall({type:"toolCall", id, name, arguments: args})` with the CANONICAL name, computes `digest = transcriptDigest([...step.messages, step.writer.output])`, calls `finish("toolUse", {type:"antigravityCli", conversationId, digest})`, sets `#ledger = {count: step.messages.length+1, digest, pendingToolCallId: id}`, resolves step.done, and returns the parked promise as the MCP response. Source: host.ts:656-671. Date: 2026-11-18. Confidence: primary.

6. FACT: Result path — the next step's `toolResult` whose `toolCallId === ledger.pendingToolCallId` selects `plan.kind="resume"`. If pending is "parked", `releasePending().settle(toMcpOutput(plan.toolResult))` settles the MCP call; `toMcpOutput` maps text/image parts to `{type:"text"/"image",...}` plus `isError: result.isError`. If pending is "detached", the actual result is sent in a NEW prompt via `lateToolResultPrompt` instead of settling the old MCP call. Source: host.ts:295-323,861-870; reconcile.ts:39-56,130-144. Date: 2026-11-18. Confidence: primary.

7. FACT: No agy-side approval exists to mimic. agy is spawned with `--dangerously-skip-permissions` and the ACP client's `requestPermission` always returns `{outcome:{outcome:"cancelled"}}`. Approval is omp's own tool loop after `finish("toolUse")`. (`SessionTools.#wrapToolForAcpPermission` is omp-as-ACP-server gating, a different path.) Source: host.ts:793,823; pi-coding-agent/src/session/session-tools.ts:1203-1246. Date: 2026-11-18. Confidence: primary.

8. INVARIANT FACT: `agy_<uuid>` id must stay stable in omp's transcript. It is minted in omp (host.ts:656), stored as `pendingToolCallId` (669), and hashed via `messageContent` toolCall part `{id,name,arguments}` (reconcile.ts:177-179); a toolResult is recognized as the continuation only when `first.toolCallId === ledger.pendingToolCallId` (reconcile.ts:47-52). Rewriting ids in the omp transcript breaks resume → falls to restore/fresh. Source: as cited. Date: 2026-11-18. Confidence: primary.

9. INVARIANT FACT: The name passed to `step.writer.toolCall` must be dispatchable by omp's tool loop; it is the canonical tool name. `normalizeToolName` lowercases built-ins and maps legacy `search`→`grep` but leaves plugin names unchanged; `isMCPToolName` checks the DOUBLE-underscore `mcp__` namespace, distinct from agy's `mcp_ide-tools_`. Any aliased outbound name MUST be reverse-mapped to canonical before line 665 or omp dispatch fails. Source: host.ts:665; pi-coding-agent/src/tools/builtin-names.ts:89-99,120-123; step-writer.ts:74-88. Date: 2026-11-18. Confidence: primary + inference.

10. INVARIANT FACT: `transcriptDigest` = sha256 of `stableStringifyJson(messageContent(message))` + "\n" per message. `messageContent` includes toolCall `{id,name,arguments}` and, for toolResult, `{role,toolCallId,toolName,isError,content}`. Rewriting any of these fields in the stored omp transcript changes the digest that was embedded in the `antigravityCli` payload, so the later restore/checkpoint lookup fails. Source: reconcile.ts:76-83,165-193. Date: 2026-11-18. Confidence: primary.

11. INVARIANT FACT: `antigravityCli` payload `{type,conversationId,digest,checkpoint?}` is written at toolUse (host.ts:668) and at turn end (751-757). `planTurn`'s "restore" requires a checkpoint AND `transcriptDigest(messages.slice(0,index+1)) === payload.digest` (reconcile.ts:61-70); `forkConversation` is bound to source id + digest. Source: host.ts:668,744-757; types.ts:1251-1259; reconcile.ts:61-70; conversation-store.ts:19-49. Date: 2026-11-18. Confidence: primary.

12. INVARIANT FACT: `toolsKey = stableStringifyJson(tools)` with `tools = (context.tools ?? []).map(toMcpTool)`; `toMcpTool` uses canonical name/description/`normalizeSchemaForMCP(toolWireSchema(tool))`. `parkedTurnMoves` is true if `process.toolsKey !== toolsKey` (or cwd/credentialVersion/systemKey/model/reasoning changed) while a non-detached call is parked; that forces `plan = planTurn(messages, undefined)` → restore/fresh and `#abandonTurn()` (host.ts:236-249). Consequence: changing tool names/descriptions/schemas between a tool call and its result abandons the parked turn and reseeds/replays. Source: host.ts:222-249; 855-859; pi-ai/src/utils/schema/normalize.ts:1345-1363; pi-ai/src/utils/schema/wire.ts:598-607. Date: 2026-11-18. Confidence: primary.

13. INVARIANT FACT: `systemKey = system` (joined system prompt); a change triggers `#loadConversation` (254) or contributes to `parkedTurnMoves` (233). Source: host.ts:224-225,233,254. Date: 2026-11-18. Confidence: primary.

14. INVARIANT FACT: single parked slot — a second concurrent call is rejected (`this.#pending` in guard, host.ts:646). `#detach` fires at holdLimitMs=165000ms, and constructor enforces hold+cancel < 180s agy MCP deadline (host.ts:46-47,180-186,572-586); release requires cancellation acknowledged with `stopReason==="cancelled"` (588-611). Source: as cited. Date: 2026-11-18. Confidence: primary.

15. INVARIANT FACT: `_meta` conversation id must be a string; non-string → MCP error -32602 (mcp-bridge.ts:172-177), and a mismatch to `conversation.id` rejects the call (host.ts:645). Source: as cited. Date: 2026-11-18. Confidence: primary.

16. SAFE (inference): keep omp transcript fully canonical; if an alias layer is wanted, apply a STABLE process-wide name/description/schema alias identically on every step so `toolsKey` never churns, and reverse-map aliased names back to canonical before `step.writer.toolCall`. Stripping `mcp_ide-tools_` in the announcer is cosmetic and safe. No id/digest payload rewrites. Source: inference over anchors 2,5,9,12. Date: 2026-11-18. Confidence: inference.

17. UNSAFE (inference): (a) rewriting omp tool name/id/args after emission; (b) changing tool schema/description across a call/result boundary (toolsKey churn → parked turn abandoned → replay as text via `replayPrompt`, losing agy conversation state); (c) dropping/altering `_meta` conversation id; (d) validating agy args against a schema different from canonical `tool.inputSchema`, which lets invalid args reach omp's real tool. Source: inference over anchors 4,8,10,12,15. Date: 2026-11-18. Confidence: inference.

18. REACHABILITY (inference): every seam in the inbound path is provider-internal (`pi-ai/src/providers/antigravity-cli/*`, `pi-ai/src/utils/schema/*`), instantiated via `streamAntigravityCli` → `AgyHost.step`. No extension-facing hook intercepts `toMcpTool`, `handleLine`, `#onToolCall`, `toMcpOutput`, `planTurn`, or `transcriptDigest`; an extension cannot perform this reverse translation without host-source modification. Final extension-API determination belongs to the ExtensionReach angle. Source: pi-ai/src/providers/antigravity-cli.ts:32-107; host.ts:152,200; mcp-bridge.ts:44-52. Date: 2026-11-18. Confidence: primary (structure) + inference (extension-api conclusion).
