2. FACT: First-party SDK publishes a distinct `BuiltinTools` enum of 15 identifiers: `list_directory`, `search_directory`, `find_file`, `view_file`, `create_file`, `edit_file`, `run_command`, `ask_question`, `invoke_subagent`, `run_workflow`, `generate_image`, `search_web`, `read_url_content`, `schedule`, `finish`; `start_subagent` deprecated alias. `read_only()` excludes `list_directory`/`search_directory`/`find_file`, noted as disabled by default. — SOURCE: https://raw.githubusercontent.com/google-antigravity/antigravity-sdk-python/main/google/antigravity/types.py lines 501-537, 542-609; docs https://antigravity.google/docs/sdk/tools.md — 2026-11-18 — [P] (SDK surface; do not conflate with CLI/IDE names — see Conflicting evidence).

3. FACT: Official MCP naming rule: eager-loaded tools are registered to the model as `mcp_<serverName>_<toolName>`; lazy-loaded (default) tools are discovered by reading `<app-data-dir>/mcp/<serverName>/<toolName>.json` (cached `name`, `description`, `parameters`) and invoked through built-in `call_mcp_tool` with `ServerName`, `ToolName`, `Arguments`. Cache dir: `~/.gemini/antigravity-cli/mcp/<serverName>/` on CLI, `~/.gemini/antigravity/mcp/<serverName>/` App/IDE. — SOURCE: https://antigravity.google/docs/mcp (Tool loading: lazy vs. eager) — 2026-11-18 — [P]. This is the owner rule that makes `mcp_ide-tools_<name>` a server-name-prefixed MCP tool (`serverName` = `ide-tools`), not a native tool name.

4. FACT: Official MCP defaults: 300 s to connect/list tools, 180 s per tool call; `timeoutSeconds` overrides both; MCP tools default to Ask permission; policy selectors `mcp(server/tool)`, `mcp(server/*)`, `mcp(*)`. Config files: global `~/.gemini/config/mcp_config.json`, workspace `<workspace>/.agents/mcp_config.json`; CLI also `/mcp` manager overlay. — SOURCE: https://antigravity.google/docs/mcp (MCP server timeouts; MCP permissions and access control; getting started by surface) — 2026-11-18 — [P].

SDK and CLI share a core engine but expose different tool-name vocabularies; do not transplant schemas. [P vs P]
- `manage_task` in hooks docs = background command/task control (list/kill/status/send_input); "Task groups" docs = IDE planning-mode UI. Same word, different layer. [P]
- Catalog seeds agy 1.5.9 roster; first-party changelog reaches 1.5.11; installed host pins an older published roster. Version drift is real. [P]
- omp's `toMcpTool` comment says the official CLI "owns any provider-specific schema conversion"; native model-visible schema shape may therefore differ from what omp hands to `tools/list`. [I from primary comment]
