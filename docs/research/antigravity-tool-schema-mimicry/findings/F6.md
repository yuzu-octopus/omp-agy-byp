## Claims

### SAFE — loop-safe if applied at a turn boundary, kept stable for the whole parked turn
- **S1 Add new tool with a new name → reaches agy.** Extension `registerTool` keys by `tool.name`; `setActiveTools` selects by names. `AgyHost.step` maps `context.tools` → `toMcpTool` → loopback MCP `tools/list`; omp keeps the bare name, agy prepends `mcp_ide-tools_`. Source: `pi-coding-agent/src/extensibility/extensions/loader.ts:246-254`; `pi-coding-agent/src/modes/runtime-init.ts:129-130`; `pi-ai/src/providers/antigravity-cli/host.ts:222,854-859`; `pi-ai/src/providers/antigravity-cli/mcp-bridge.ts:155-157`; `omp://providers.md` §Antigravity CLI ("Tool names remain bare in omp; agy presents them to the model as `mcp_ide-tools_<name>`"). 2026-11-18 **P**.
- **S2 Change tool descriptions/schemas.** Projection uses exactly `name`, `description`, `inputSchema` (schema via `toolWireSchema` + `normalizeSchemaForMCP`); no provider-side CCA normalizer on this path. Host validates args against the advertised schema and returns a schema-aware error so the model can correct the call. Source: `host.ts:854-859,653-655,883-920`; `pi-ai/src/utils/schema/normalize.ts:1345-1364`. 2026-11-18 **P**.
- **S3 Per-turn system prompt, at a turn boundary.** `before_agent_start` handlers can replace `systemPrompt: string[]`; results chain in registration order. Joined prompt is shipped on `newSession`/`loadSession` as `_meta: { antigravity: { systemPrompt: { append: system } } }`. `systemKey` is compared per step, so a change while a tool turn is parked forces abandon/reseed — do it only at a boundary. Source: `pi-coding-agent/src/extensibility/extensions/runner.ts:2645-2699`; `host.ts:224-225,254,267-282,483-500,845-847`. 2026-11-18 **P**.
- **S4 Tool-call / result traffic shaping, without touching ids.** `tool_call` handlers may block or revise `input` and attach `additionalContext`; revised input is revalidated against the tool schema and the user approves what actually runs. `tool_result` handlers may replace `content`/`details`/`isError` and attach `additionalContext`. Must preserve call ids, names and call/result pairing. Source: `pi-coding-agent/src/extensibility/shared-events.ts:345-375,383-412,418-434`. 2026-11-18 **P**.
- **S5 Message/context shaping that preserves digest-covered content.** `context` can reshape `AgentMessage[]` before provider conversion; safe iff the exact prefix covered by `antigravityCli` digests, tool-call ids and tool-result pairing survive (see U6/F4). Source: `reconcile.ts:39-83,165-193`; `host.ts:656-669,742-757`; pointer `docs/research/omp-antigravity-investigation/F-antigravity-cli-hooks.md:45` (**S**, mechanism re-verified here **P**). 2026-11-18 **P**.
- **S6 New provider under a non-reserved api id delegating to the built-in transport** — `registerCustomApi` rejects only built-in ids, so a wrapper api id is registrable; it must reproduce the whole `AssistantMessageEventStream`/ACP loop. Feasibility is **[INFERENCE]** (no wrapper built/tested); reservation fact **P**: `pi-ai/src/api-registry.ts:19-51,72-93`.

### UNSAFE — internal contracts; renaming = dispatch break or no-op
- **U1 Built-in tool IDs.** Fixed canonical set: `read, bash, edit, ast_grep, ast_edit, ask, debug, eval, github, glob, grep, find, lsp, checkpoint, rewind, context_notes, new_context, security_scan, task, wait, todo, web_search, write, memory_edit, retain, recall, reflect, learn, manage_skill`; hidden set `yield, goal, think`. Renaming in prompts/registry breaks resolution and hard-wired logic: `read`/`write` are the `xd://` device transport; `write` is force-added when devices are mounted; `think` is force-included for external thinking and used as a named tool choice. Source: `pi-coding-agent/src/tools/builtin-names.ts:3-33,85-99`; `pi-coding-agent/src/tools/essential-tools.ts:1-16,23-37`; `pi-coding-agent/src/sdk.ts:4766-4768`; `pi-coding-agent/src/session/agent-session.ts:9123-9130`; `pi-coding-agent/src/tools/index.ts:762-764`; `pi-coding-agent/src/session/session-tools.ts:2579-2592`. 2026-11-18 **P**.
- **U2 `mcp__<server>_<tool>` minting.** `createMCPToolName` joins with a SINGLE `_`, sanitizes parts, caps at 64 chars with deterministic `Bun.hash` suffix; legacy digit-era key exists as a fail-closed approval fallback; doubled-`__` model spellings are normalized through candidate re-minting, not fuzzy matching. This namespace is distinct from agy's `mcp_ide-tools_`. Source: `pi-coding-agent/src/mcp/tool-bridge.ts:535-574,576-645`; `pi-coding-agent/src/tools/builtin-names.ts:120-123`. 2026-11-18 **P**.
- **U3 `mcp_ide-tools_` prefix is agy-owned.** Installed omp never mints it: it only strips the prefix from ACP `tool_call` titles for announcement matching. Official omp doc states agy presents omp's bare names under that prefix. An extension renaming this prefix is a **no-op** on omp and cannot reconfigure agy. Source: `host.ts:48,709-715`; `pi-ai/src/providers/antigravity-cli/mcp-bridge.ts:1-4`; `omp://providers.md` §Antigravity CLI. 2026-11-18 **P** (omp side) / **S** (agy-side behavior, documented not independently inspected).
- **U4 `agy_<uuid>` call ids.** Minted when a tool call parks; stored as ledger `pendingToolCallId`; resume requires the first trailing `toolResult.toolCallId` to equal it. A mismatch throws "tool continuation was interrupted". Call ids are not a rename surface. Source: `host.ts:318-321,656-669`; `pi-ai/src/providers/antigravity-cli/reconcile.ts:17-22,47-56`. 2026-11-18 **P**.
- **U5 Internal URL schemes are host-resolved resources, not aliases.** 20 built-ins registered process-globally (`skill, rule, memory, out, agent, history, artifact, local, proc, cfg, ssh, security, vault, issue, pr, mr, mcp, omp, xd, attachment, conflict`); `isBuiltin()` blocks host shadowing; extension `registerLinkScheme` throws for standard/OMP-internal schemes; RPC `setSchemes` throws on reserved schemes; all parsing must use `parseInternalUrl`, not `new URL()`. Rewriting `omp://`, `local://`, `artifact://`, `agent://`, `proc://`, `skill://`, `ssh://`, `pr://` to invented schemes removes the resolver. Source: `pi-coding-agent/src/internal-urls/router.ts:107-134,177-180,182-195`; `pi-coding-agent/src/extensibility/extensions/loader.ts:339-351`; `pi-coding-agent/src/modes/rpc/host-uris.ts:94-108`; `pi-coding-agent/src/internal-urls/parse.ts:1-11`. 2026-11-18 **P**.
- **U6 `antigravityCli` payload + digests + keys.** Payload = `{type:"antigravityCli", conversationId, digest, checkpoint?}` written on `toolUse` and turn end. `transcriptDigest` = sha256 over `stableStringifyJson` of model-visible content, explicitly including tool-call `id`/`name`/`arguments` and tool-result `toolCallId`/`toolName`. `toolsKey = stableStringifyJson(tools)`; `systemKey = joined system prompt`. `planTurn` resumes only an exact digest-matching prefix; else restores a matching checkpoint or reseeds. Source: `pi-ai/src/types.ts:1238-1267`; `host.ts:223-225,230-235,244-254,656-669,742-757`; `reconcile.ts:27-83,165-193`. 2026-11-18 **P**.
- **U7 agy-internal tools are out of omp's namespace.** Official doc: omp's built-in agent prompt/coding tools are removed, but agy's `manage_task` and MCP resource tools remain internal to agy. The injected agent definition declares `tools: []`, `excludeDefaultComponents: true`, `inheritCustomizations: false`. They cannot be renamed from an omp extension. Source: `omp://providers.md` §Antigravity CLI; `pi-ai/src/providers/antigravity-cli/agent.md:1-9`. 2026-11-18 **P**.

### Failure modes — mechanism + anchor
- **F1 Tool-loop detachment.** (a) Unknown/renamed tool at `tools/call` → JSON-RPC `-32602` and host `#fail` ("requested an unknown tool"); (b) duplicate projected tool name → `McpBridge` constructor throws at process start; (c) any change to toolsKey/cwd/credentialVersion/systemKey/model/effort while a call is parked (`state !== "detached"`) → `parkedTurnMoves` → `#abandonTurn()`, parked call settled as cancelled; (d) agy's 180s MCP deadline → `#detach()` after 165s hold + 5s cancel, with late result delivered only in a new turn; (e) `tools/call` `_meta["antigravity.google/conversation_id"]` mismatch → rejected as "outside the active step". Source: `mcp-bridge.ts:52-53,158-177`; `host.ts:180-186,227-249,572-586,613-624,626-652`. 2026-11-18 **P**.
- **F2 Cache invalidation / reseed.** toolsKey change restarts the agy process; systemKey change triggers `loadSession` reload; digest mismatch makes `forkConversation`/`readConversationCheckpoint` fail → full transcript replay as text. Renaming a tool therefore invalidates the live conversation even when the model still calls something syntactically valid. Source: `host.ts:223-249,254,255-277,742-749`; `reconcile.ts:58-72`. 2026-11-18 **P**. Direct-CCA contrast: changing tool declarations can also shift prompt-cache prefixes — documented generally in `omp://provider-quirks.md` for HTTP providers; ACP-side prompt-cache effect **unverified** by me.
- **F3 Schema rejection.** Invalid projected schema → `toMcpTool` throws (process setup fails); unsupported JSON-Schema keywords are stripped/lifted by `normalizeSchemaForMCP`; invalid model arguments are rejected by the host with failing paths + expected schema; MCP-origin names over 64 chars get a hash suffix (strict-validator limit). Source: `host.ts:853-859,653-655,883-920`; `normalize.ts:1345-1364`; `pi-coding-agent/src/mcp/tool-bridge.ts:549-569`. 2026-11-18 **P**.
- **F4 Signature/digest mismatch.** Rewriting tool names, ids, arguments or tool-result names in `context` (or renaming mid-turn) changes `transcriptDigest`: `planTurn` no longer resumes, the `antigravityCli` checkpoint digest no longer matches, resume with a pending tool is refused. This is the ACP analogue of "signature mismatch"; encrypted thinking-signature replay errors are a direct-CCA concern and were **not** observed on this path — that link is **[INFERENCE]**. Source: `reconcile.ts:39-73,75-83,165-193`; `host.ts:656-669,742-757`. 2026-11-18 **P** (digest mechanism).
- **F5 Approval mismatch.** Approvals are keyed by `tool.name` / `policyKey` (`tools.approval.<name>`) and grants are recorded against `tool.name`; renaming changes the config key and grant identity, so a grant/deny silently stops applying. `write` is additionally the `xd://` gate and is force-added when devices are mounted. agy-side permission requests are always answered `cancelled` and the child runs `--dangerously-skip-permissions`: omp owns execution/approval. Source: `pi-coding-agent/src/tools/approval.ts:241-258,346-364`; `essential-tools.ts:1-16`; `sdk.ts:4766-4768`; `host.ts:793,821-827`. 2026-11-18 **P**.
- **F6 Version drift.** Bundled roster follows agy 1.5.9; managed binary is SHA-512-verified with at most daily update checks; `PI_AGY_PATH` bypasses download/verification; argv and `_meta` shape are hard-coded. Any agy change to `_meta` acceptance, MCP-bridge framing or tool naming can break the adapter; no live/newer agy was inspected. Source: `omp://providers.md` §Antigravity CLI; `pi-ai/src/providers/antigravity-cli/binary.ts:29-49`; `host.ts:783-802,845-847`. 2026-11-18 **P** for omp facts; impact of future agy versions **[INFERENCE]**.
- **F7 No-op rules (attempts that do nothing on this path).** (a) `onPayload`/`onResponse` are never read by `streamAntigravityCli` — `before_provider_request` / `after_provider_response` do not fire (contrast direct CCA: `buildRequest` → `await options?.onPayload?.(requestBody, model)` → replacement, where tool declarations ARE in that body); (b) `Tool.customWireName` is honored by the general dispatcher but **ignored** by `toMcpTool`, which projects `tool.name`; (c) `mcp__<server>_<tool>` minting is irrelevant to agy's `mcp_ide-tools_*` view; (d) registering reserved schemes/api ids throws rather than overriding; (e) `normalizeToolName` canonicalizes only known built-ins/aliases and leaves other plugin names unchanged — a plugin calling itself `READ` canonicalizes to `read` (collision), not a new identity. Source: `pi-ai/src/providers/antigravity-cli.ts:17-20,48-72`; `pi-ai/src/providers/google-gemini-cli.ts:605-609`; `host.ts:854-859`; `pi-agent-core/src/agent-loop.ts:2949-2961`; `builtin-names.ts:95-99`; `loader.ts:347-349`; `api-registry.ts:72-75`. 2026-11-18 **P**.
